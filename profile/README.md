# LARP

Vulnerability research, done by hand.

LARP is a team of vulnerability researchers and bug hunters. We find security bugs in software
people rely on. We report each bug to the vendor, and we publish the details once the vendor ships
a fix.

## Reporting a vulnerability

Do not open a public issue. Report privately. Read https://larp-security.com/.well-known/security.txt
for the current contact address and PGP key.

We work to a 90 day disclosure window. We credit the reporter in the published write-up unless the
reporter asks us not to.
